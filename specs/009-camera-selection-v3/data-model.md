# Data Model: Camera Selection V3

## Splat Patching Config

Fields:

- `max_cameras`: Positive integer final hard cap for selected cameras.
- `external_support_fraction`: Float from `0.0` to `1.0`, default `0.10`.
- `buffer`: Existing scene-relative patch buffer.
- `patch_ids`: Optional patch subset.

Derived values:

- `external_support_allowance = floor(max_cameras * external_support_fraction)`
- `internal_patch_target = max_cameras - external_support_allowance`

Validation:

- `max_cameras > 0`
- `0.0 <= external_support_fraction <= 1.0`
- `internal_patch_target > 0`

## Patch Footprint

Fields:

- `patch_id`
- `bounds.min_x`, `bounds.max_x`, `bounds.min_y`, `bounds.max_y`, `bounds.min_z`, `bounds.max_z`
- `bounds.buffer`

Relationships:

- Generated by wildflow using `internal_patch_target`.
- Stored in `patch_metadata.json["bounds"]`.
- Used as the complete rectangular footprint for internal classification and overlap.
- Intersected with each candidate camera's frustum footprint on a local fitted patch plane for `footprint_overlap_score`.

Validation:

- Nested bounds must exist.
- X/Y/Z min values must be less than max values.

## Camera Evidence Record

Fields:

- `image_id`
- `image_name`
- `source_patch`
- `pool`: `internal` or `external`
- `selection_role`: `kept_internal`, `rejected_internal`, `selected_external`, or `unused_external`
- `visible_patch_track_count`
- `normalised_track_score`
- `footprint_overlap_score`
- `target_image_share`
- `external_evidence_score`
- `azimuth_degrees`
- `azimuth_spread_score`
- `external_score`
- `camera_x`, `camera_y`, `camera_z`

Relationships:

- Belongs to one patch selection.
- Internal records come from cameras inside the patch footprint.
- External records come only from one-ring neighbouring patches.
- `visible_patch_track_count` is counted from COLMAP sparse point observations inside the patch rectangle.
- `footprint_overlap_score` is `area(camera_frustum_footprint_on_fitted_patch_plane ∩ patch_rectangle) / area(patch_rectangle)`.
- `target_image_share` is the projected patch/frustum intersection polygon area divided by image area.

Validation:

- Records with projected intersection polygons under three vertices have `footprint_overlap_score = 0` and `target_image_share = 0`.
- Useful cameras require `target_image_share >= 0.05` and either positive track evidence or positive footprint evidence.
- Sparse points may fit the projection plane, but sparse-point hulls, sparse-point bounding boxes, and sparse-point density are not valid footprint or target-image-share geometry.

## Patch Selection

Fields:

- `patch_id`
- `selected_images`
- `selected_internal_count`
- `rejected_internal_count`
- `selected_external_count`
- `unused_external_count`
- `max_cameras`
- `external_support_fraction`
- `external_support_allowance`
- `internal_patch_target`
- `camera_evidence_records`
- `warnings`

State transitions:

- Candidate collection -> evidence scoring -> useful internal kept -> useful neighbouring external ranked -> final selected set -> diagnostics/export.

Validation:

- Selected camera count never exceeds `max_cameras`.
- Selected external count never exceeds `external_support_allowance`.
- No selected external camera comes from a non-neighbouring patch.
- Useful internal count exceeding `max_cameras` is a patch-bound generation defect.
- Warnings are emitted when patch-level footprint coverage is below `0.25` or any selected camera target image share is within `0.01` of the `0.05` minimum.

## Camera Selection Diagnostic

Files:

- `camera_coverage.csv`
- `plot.png`
- `plot.html`
- `histogram.png`
- `generation.log`

Required contents:

- Counts for kept/rejected internal and selected/unused external cameras.
- V3 config and derived target values.
- Target image share, footprint overlap, track score summaries.
- Warnings.
- Visual distinction between the four camera categories.

## Validation Sweep Output

Fields/files:

- `summary.csv`
- `review_notes.md`
- PNG-only folders for Dataset 1/Dataset 2 support fractions `0.05`, `0.10`, `0.15`
- Known-bad comparison folders for Dataset 1 p002 and p007

Validation:

- Each sweep patch PNG follows `pNNN_camera_selection.png`.
- Summary rows include dataset, support fraction, patch id, selected counts, warnings, and output path.
