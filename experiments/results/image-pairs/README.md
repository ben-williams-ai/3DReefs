# LPIPS image-pair examples

These are the lowest- and highest-LPIPS held-out image comparisons for each
dataset in the completed per-image evaluation. The ground-truth image is on the
left and the corresponding 3DGS render is on the right. Filenames record the
dataset, rank, LPIPS score and source image name.

The tracked JPEGs are 3,200-pixel-wide review copies derived from the original
full-resolution LFS comparison PNGs. Full-resolution inputs and the complete
per-image score tables remain in the local `data/patch-results/` evidence tree.
